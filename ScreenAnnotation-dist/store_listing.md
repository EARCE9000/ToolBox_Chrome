# Chrome Web Store 掲載情報ドラフト

## 拡張機能名
ScreenAnnotation - 矢印注釈

## 簡単な説明(132文字以内・ストア一覧に表示される)
Webページ上に番号付きの矢印を追加して注釈できるシンプルな拡張機能。クリックで追加、クリックで削除。

## 詳細説明
Webページのスクリーンショットを撮る前に、伝えたい箇所を矢印で示せるシンプルな注釈ツールです。

【使い方】
1. 拡張機能アイコンをクリックすると、ページ中央付近に番号付きの矢印が追加されます
2. 矢印をドラッグして、示したい場所に移動できます
3. 矢印をクリック(ドラッグせずに)すると、その矢印だけを削除できます。残りの矢印の番号は自動的に詰め直されます
4. 拡張機能アイコンを右クリックし「矢印をすべてクリア」を選択すると、ページ上の矢印を一括で削除できます

矢印はそのタブの表示上に重ねているだけで、ページを再読み込みすると自然にリセットされます。

本拡張機能はユーザーがアイコンをクリック/右クリックメニューを操作した瞬間のみ、そのタブに一時的にスクリプトを読み込みます(activeTab権限)。常時すべてのサイトを監視・記録するような権限は要求していません。

## 権限の使用理由(プライバシー慣行タブへの入力用)

- **activeTab**: ユーザーが拡張機能アイコンをクリック、または右クリックメニューから操作した現在のタブにのみ、矢印描画用のスクリプトとスタイルを注入するために使用します。ユーザー操作なしにページへアクセスすることはありません。
- **scripting**: activeTab で許可された対象タブに、矢印の追加・削除を行うコンテンツスクリプト(content.js/content.css)を注入するために使用します。
- **contextMenus**: 拡張機能アイコンの右クリックメニューに「矢印をすべてクリア」の項目を追加するために使用します。

## データ収集について
本拡張機能は、ユーザーデータを収集・送信・保存しません。矢印の位置情報はタブの表示上にのみ保持され、外部サーバーへの通信は一切行いません。
